# Информационная система «Автошкола»

## Описание проекта
Учебный проект по разработке базы данных для учёта учебного процесса автошколы.

## 🎨 Руководство по стилю
- **Логотип и иконка:** (здесь можно указать путь к файлу, например `logo.png`)
- **Основной цвет:** `#4CAF50` (зелёный)
- **Дополнительный цвет:** `#212121` (тёмно-серый)

## 🗄️ Структура базы данных
Проект включает в себя 12 основных таблиц, включая:
- `Student` (Учащиеся)
- `Instructor` (Инструкторы)
- `Group` (Учебные группы)
- `Lesson` (Занятия)
- `Payment` (Оплата) и другие.

## 🚀 Как запустить
1.  Установите PostgreSQL.
2.  Создайте базу данных `driving_school`.
3.  Выполните SQL-скрипт из файла `database_script.sql`.
